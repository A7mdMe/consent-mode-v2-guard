Google Consent Mode v2 Static Syntax Scanner

Quickly inspect static HTML text for Consent Mode v2 parameter declarations and basic script sequence.

Technical Scope Note: This scanner performs static string matching on source text. It does not verify browser runtime execution, dynamic tag triggering, GTM container state, network collect payloads (e.g. encrypted gcd parameters), or GDPR legal compliance. Use official tools like Google Tag Assistant for runtime testing.
